نهمینو — نسخه ۲ قابل انتشار مستقیم روی Cloudflare Pages

مهم: فقط فایل index.html برای نمایش کل سایت لازم است. پوشه assets لازم نیست.

روش جایگزینی در GitHub (مخزن متصل به Cloudflare):
1. وارد مخزن Nohomi. شوید و فایل index.html را باز کنید.
2. روی Edit (مداد) بزنید، کل محتوای قدیمی را پاک کنید و متن فایل index.html جدید را جایگزین کنید؛ سپس Commit changes را بزنید.
3. روش راحت‌تر روی رایانه: فایل قدیمی index.html را در GitHub حذف/جایگزین کنید و فایل index.html جدید را از طریق Add file > Upload files به ریشه همان مخزن اضافه کنید؛ Commit changes بزنید.
4. در Cloudflare Pages > Deployments موفق شدن آخرین انتشار را بررسی کنید و سایت را باز کنید.
5. تنظیمات: Framework=None، Build command خالی، Build output directory=.

توجه بسیار مهم:
- رابط، درس‌ها، مدیریت محتوای محلی، پیوست‌های محلی، آزمون و تصحیح تستی، گزارش‌های روزانه/هفتگی/ماهانه، و پنل ساخت دستور AI پیاده شده‌اند.
- این نسخه آزمایشی است: حساب‌ها و نقش‌ها نمایشی‌اند و نباید برای آزمون محرمانه یا نمره واقعی دانش‌آموز استفاده شوند.
- مطالب فقط در مرورگر همان دستگاه ذخیره می‌شوند. بخش اطلاعات مشترک و Gemini/OpenAI هنوز به سرور/دیتابیس متصل نیست.
- امکان پشتیبان‌گیری JSON برای متون موجود است اما فایل‌های پیوست در آن نیستند.
- بخش AI فقط دستور قابل کپی می‌سازد و مسیر سروری آماده برای توسعه دارد؛ در این نسخه هوش مصنوعی واقعاً متصل نیست.
- هیچ رمز شخصی یا کلید API را در فایل‌های HTML عمومی قرار ندهید.
